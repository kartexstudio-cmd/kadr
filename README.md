# Nitroreel

Лендинг студии видеокреативов для мобильных игр: UA/перформанс-креативы, трейлеры,
cinematic-ролики, 3D/2D-анимация.
Next.js 16 (App Router) · React 19 · Tailwind v4 · Supabase.

Двуязычный (`/ru`, `/en`), тёмная кинематографичная тема, форма заявки пишет лиды в Supabase.

```bash
npm run dev      # http://localhost:3000
npm run build
npm run lint
npx tsc --noEmit
```

Как проект устроен — в [`CLAUDE.md`](CLAUDE.md). Как передать проект и запустить его
без опыта разработки — в [`HANDOFF.md`](HANDOFF.md).

## Видео: где хостить и как переехать

Сейчас в `public/media/` лежат локальные заглушки — открытые тест-ролики. Для продакшна
их нужно заменить, и почти наверняка вынести с сервера сайта на видеохостинг.

### Почему не Google Drive

Диск отдаёт файлы не как видеопоток: нет HLS, нет адаптивного качества, нет CDN
рядом с пользователем. Прямые ссылки нестабильны, при трафике включается квота, а
перемотка по длинному ролику работает плохо. Для витрины агентства это заметно.

### Почему не `public/`

Файлы в `public/` едут через Vercel как статика. Это работает, но: гигабайты видео
попадают в git и в каждый деплой, весь ролик тянется одним файлом без переключения
качества, а исходящий трафик считается по тарифу Vercel. Годится для пары коротких
лупов, не для портфолио.

### Что брать

| | Цена | Когда стоит брать |
|---|---|---|
| **Bunny Stream** | ~$5/мес + $0.01/ГБ трафика | Дефолт для такого сайта. Дёшево, свой плеер, HLS и постеры из коробки |
| **Cloudflare Stream** | $5 за 1000 мин хранения + $1 за 1000 мин просмотра | Если уже живёте на Cloudflare |
| **Mux** | Дороже, посекундная тарификация | Если нужна аналитика досмотров и качество плеера уровня продукта |

Все три уже поддержаны в коде.

### Как переехать

Компоненты про хостинг ничего не знают — они получают `VideoSource` и зовут
`resolveVideo()` из [`src/lib/video.ts`](src/lib/video.ts). **Правится только `provider`
у записей в [`src/lib/content.ts`](src/lib/content.ts).**

Было:

```ts
{ provider: "file", src: "/media/work-01.mp4", poster: "/media/work-01.jpg" }
```

Стало:

```ts
{ provider: "bunny", libraryId: "12345", videoId: "abc-def", poster: "/media/work-01.jpg" }
// { provider: "mux", playbackId: "..." }                                  — постер подтянется сам
// { provider: "cloudflare", customerCode: "...", videoId: "...", poster: "..." }
```

`resolveVideo()` вернёт `kind: "file"` (нативный `<video>`) или `kind: "embed"` (iframe),
и карточки с лайтбоксом отработают одинаково. Границу между `video.ts` и компонентами
ломать не надо — она и существует ради этого переезда.

Постеры лучше оставить своими: они грузятся сразу, а плеер — только по клику
(facade-паттерн), поэтому качество постера важнее, чем кажется.

### Забрать видео с Google Drive

```bash
rclone config                          # добавить remote типа drive
rclone copy gdrive:Видео ./raw -P
```

Перед загрузкой на хостинг стоит перегнать в web-профиль:

```bash
ffmpeg -i raw/in.mov -c:v libx264 -crf 20 -preset slow \
  -c:a aac -b:a 128k -movflags +faststart out.mp4
```

`+faststart` двигает индекс в начало файла — без него браузер ждёт полной загрузки
перед стартом воспроизведения.

## Приём заявок

Форма шлёт данные в server action [`src/app/actions.ts`](src/app/actions.ts): honeypot →
zod → rate limit (3/мин на IP) → `insert` в Supabase через service-role клиент.

Чтобы включить: выполнить [`supabase/leads.sql`](supabase/leads.sql) в SQL Editor и
заполнить `.env.local` по образцу `.env.example`.

Без переменных окружения форма **не падает** — логирует warning и отдаёт `success`.
Это сделано намеренно, чтобы сайт оставался рабочим локально и в превью.

`SUPABASE_SERVICE_ROLE_KEY` — только серверный, никогда не префиксовать `NEXT_PUBLIC_`.

## Деплой на Vercel

1. Залить репозиторий на GitHub и импортировать в Vercel — фреймворк определится сам.
2. Прописать в Environment Variables: `NEXT_PUBLIC_SITE_URL` (боевой домен),
   `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`.
3. Проверить после деплоя: редирект `/` → `/ru`, переключатель языка, `/sitemap.xml`,
   `/robots.txt`, отправку формы.

Rate limit хранит счётчик в памяти процесса, поэтому на нескольких инстансах
ограничение работает в пределах каждого. Осознанный компромисс: если понадобится
жёстче — Upstash Redis или Vercel KV.
