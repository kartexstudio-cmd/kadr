# Nitroreel — лендинг студии видеокреативов для мобильных игр

Одностраничный сайт-портфолио студии Nitroreel: UA/перформанс-креативы, трейлеры и
cinematic-ролики, 3D/2D-анимация для мобильных игр. Двуязычный (ru/en), с формой заявки,
которая пишет лиды в Supabase. Ранее сайт назывался KADR и был позиционирован как студия
для брендов в целом — не путай со старыми упоминаниями в истории git и в этом файле.

**Ключевое УТП (с 2026-08-11): визуал делаем через AI-инструменты, не классическим
продакшном.** Дешевле и быстрее ручной съёмки/рендера, не уступает по качеству, и
благодаря этому тестируем в разы больше вариаций хуков на тот же бюджет (20+ вместо
8–10 в батче). **AI — аргумент в тексте (почему дешевле/быстрее/больше тестов), а не
громкий заголовок** — не выноси «AI» в hero-заголовки или h1 без явного запроса
владельца. Это касается вообще всех услуг, включая трейлеры и «3D/CGI» — там тоже теперь
AI-генерация, а не ручной рендер. Не пиши в текстах «реальные актёры», «снимаем сами»,
«не постановка» как противопоставление — это прямо противоречит позиционированию.

**Общайся с пользователем по-русски.** Весь контент сайта и комментарии в коде — на русском.

## Стек

Next.js 16.3 (App Router) · React 19.2 · TypeScript · Tailwind CSS v4 · motion v13 · zod v4 · Supabase JS v2

## Запуск

```bash
npm run dev     # localhost:3000, редиректит на /ru или /en
npm run build
npm run lint
npx tsc --noEmit
```

**Важно про окружение (Windows).** Node v24 лежит в `C:\Program Files\nodejs` и прописан
в системном PATH, но у сессии может быть унаследован устаревший PATH без него. Два грабля:

- **bash:** если `npm: command not found` — выполни
  `export PATH="/c/Program Files/nodejs:$PATH"`.
- **PowerShell:** `npm` там разрешается в `npm.ps1`, а ExecutionPolicy = `Restricted`,
  поэтому падает с «running scripts is disabled on this system». Вызывай **`npm.cmd`**
  вместо `npm` — это обходит проблему без изменения настроек системы.

Проверено: `npm.cmd run build` и `npx tsc --noEmit` проходят чисто (9 маршрутов, ru/en).

## Архитектура

### Локализация — своя, без библиотек

- `src/lib/i18n/config.ts` — locales `["ru", "en"]`, дефолт `ru`, гард `isLocale()`.
- `src/lib/i18n/dictionaries.ts` — объект `ru`, затем `type Dictionary = typeof ru` и
  `const en: Dictionary`. Поэтому **пропущенный или лишний ключ в `en` — ошибка компиляции,
  а не runtime-баг**. Проверяется через `npx tsc --noEmit`.
- `src/proxy.ts` — в Next.js 16 middleware переименован в **proxy**. Файл определяет
  локаль (cookie `locale` → `Accept-Language` → дефолт) и редиректит `/` → `/ru`.
  Матчер исключает `_next`, `media`, `api`, `favicon.ico`, `robots.txt`, `sitemap.xml`.
- Все страницы под `src/app/[lang]/`. `params` — Promise, его нужно `await`.

**Правило:** любой новый текст идёт в `dictionaries.ts` в оба языка. Хардкод строк
в компонентах — только для служебной разметки.

### Контент

`src/lib/content.ts` — единственный источник данных портфолио: `works` (6 кейсов, у
каждого есть `category: "ua" | "trailer"` — используется фильтром в блоке «Работы»,
см. `work-grid.tsx`), `reels` (4 вертикальных), `genres` (строки для бегущей строки
форматов/жанров). Локализуемые поля — тип `Localized = Record<Locale, string>`, то
есть `{ ru: "...", en: "..." }`.

**Полей `clients` в `content.ts` нет и не появится без явной просьбы владельца.**
2026-08-11 на главной ненадолго появлялась лента «Нам доверяют команды из…» (второй
инстанс `ClientsMarquee`, строился из `works.map(w => w.client)`) — владелец попросил
убрать её **в тот же день**: кейсы в `works` демо-шные (см. «Что в проекте ненастоящее»
ниже), студия ни с одной из них реально не работала, и лента «нам доверяют» вводила
посетителей в заблуждение. Не возвращай этот блок, пока не появится настоящее
портфолио — тогда это осознанный шаг владельца, а не автоматическое решение агента.

### Видео — абстракция над провайдером

`src/lib/video.ts` — `resolveVideo()` превращает `VideoSource` в готовый плеер.
Поддерживает `file` (локальный mp4), `bunny`, `mux`, `cloudflare`. Возвращает
`kind: "file"` (нативный `<video>`) или `kind: "embed"` (iframe).

**Чтобы переехать на CDN, правится только `provider` у записей в `content.ts`** —
компоненты не трогаются. Это сделано намеренно, не ломай эту границу.

### Форма заявки

`src/app/actions.ts` — server action `submitLead(prevState, formData)`, используется
через `useActionState` в `src/components/site/contact-form.tsx`. Защита слоями:

1. **Honeypot** — скрытое поле `website`. Заполнено → возвращаем `success`, ничего не пишем.
2. **zod-схема** — обязательны `name` (2–120), `email`, `message` (10–4000), `consent === "on"`.
3. **Rate limit** — 3 заявки в минуту на IP, счётчик в `Map` в памяти процесса.
   На serverless это работает только в пределах одного инстанса — осознанный компромисс.
4. **Доставка в два независимых канала** — `saveLead()` (Supabase) и `notifyTelegram()`
   (`src/lib/telegram.ts`) запускаются через `Promise.all`.

Каждый канал возвращает `DeliveryResult`: `ok` | `skipped` (нет ключей) | `failed`.
Форма отдаёт `success`, если доставил хотя бы один канал **или** не настроен ни один
(локальная разработка). `error` — только когда настроенные каналы упали все до одного:
заявка потеряна, и молчать об этом нельзя. **Не сводите это к «упал insert → ошибка»** —
бесплатный Supabase засыпает, и тогда Telegram остаётся единственным каналом.

Отправка в Telegram — простым текстом, **без `parse_mode`**: `_`, `*` или `<` в имени
клиента иначе ломают запрос. Таймаут 5 с, ошибки только логируются.

`src/lib/supabase.ts` → `getSupabaseAdmin()` возвращает `null`, если переменных нет.
Тогда action логирует warning и **всё равно отдаёт `success`** — сайт остаётся рабочим
без ключей. Это не баг, это специально для локальной разработки и превью.

`SUPABASE_SERVICE_ROLE_KEY` — только серверный. **Никогда не префиксуй его `NEXT_PUBLIC_`.**

### Чат-виджет поддержки

`src/components/site/chat-widget.tsx` — кнопка внизу справа, разворачивает окно чата.
Без Framer Motion: пробовал `AnimatePresence`, но в headless/фоновых вкладках (в т.ч. в
этом Browser pane) rAF подвисает и монтирование через мотион зависало — теперь это
обычный условный рендер `{open && (<div>...)}`, без анимации входа/выхода. Если решишь
вернуть анимацию — проверяй сначала на **реальном** фронтированном окне, не в этом pane.

`src/app/api/chat/route.ts` — POST-роут, дёргает Gemini (`gemini-flash-latest`, бесплатный
тир Google AI Studio, ключ `GEMINI_API_KEY`). Системный промпт собирается из **тех же
данных**, что показаны на сайте (`t.faq.items`, `t.services.items` из `dictionaries.ts`) —
единый источник правды: правишь FAQ на сайте, бот отвечает по-новому без правок в роуте.

Нюансы, за которые уже заплачено временем на дебаг:

- **`thinkingConfig: { thinkingLevel: "low" }` обязателен.** Модели линейки Gemini 3 не
  дают полностью выключить reasoning, а он ест `maxOutputTokens` раньше самого ответа —
  без этого при небольшом лимите токенов ответ обрезается в пустоту. Держим `"low"` +
  `maxOutputTokens: 1024` с запасом.
- **Ретрай на сетевую ошибку — не опционально.** Долгоживущий Node-процесс дев-сервера
  время от времени ловит `ECONNRESET` на переиспользованном keep-alive сокете к Gemini
  (свежий процесс/новый сокет — проблемы нет). Один ретрай в `route.ts` закрывает это.
- Rate limit — тот же паттерн, что в `actions.ts` (Map в памяти, IP → окно), но лимит
  ниже (6/мин) — с запасом от бесплатной квоты Gemini, чтобы виджет деградировал на
  своих условиях, а не ловил 429 от Google посреди диалога.
- Если `GEMINI_API_KEY` не задан — роут отдаёт `503`, виджет должен показать
  `errorFallback` и не падать. Проверено вручную (см. `.env.local`).

### База

`supabase/leads.sql` — таблица `public.leads`. RLS включён, политик нет вообще:
анонимный ключ не может ни читать, ни писать. Вставка идёт только через service_role,
который RLS обходит. Выполняется вручную в Supabase → SQL Editor.

**Keepalive.** `vercel.json` объявляет ежедневный Cron на `/api/keepalive`
([`src/app/api/keepalive/route.ts`](src/app/api/keepalive/route.ts)) — лёгкий `select`
к `leads`, чтобы бесплатный Supabase не засыпал после ~недели без обращений. Маршрут
принимает только запросы с `Authorization: Bearer <CRON_SECRET>` — этот заголовок Vercel
подставляет сам при вызове по расписанию. Без него — `401`.

  Blender-заглушки (Big Buck Bunny и т.п.) удалены.

  клипов, а отдельный ролик «Tower Def_2.5d» (2.5D tower defense, геймплей на гекс-сетке)
  из папки `C:\Cloude\Video For Site\`. Сжат под тот же профиль, что был у склейки:
  `ffmpeg -vf scale=1280:720 -an -c:v libx264 -crf 23 -preset slow -movflags +faststart`
  (исходник 1920×1080/50 Мбит/с/111 МБ → 1280×720/~2 Мбит/с/4.6 МБ, звук вырезан — хиро

  (`-ss 2 -vframes 1`), не файл `0720.jpg` из той же папки — тот вообще не по теме
  (случайный чужой YouTube-thumbnail с пранком, не скриншот игры).
  **Лежат локально** — это ~46 МБ в `public/`, актуальность переезда на видеохостинг

- **Кейсы, клиенты (`Vortex Play`, `NeonDash Games` и т.п.), метрики, отзывы** в `content.ts`

  цифры результатов — нет). Названия/теги карточек по возможности подобраны в тему
  реального видео в слоте — если меняешь видео в `work-XX`, проверь, не разъехался ли
  заголовок с содержимым ролика.
- **Домен настоящий** — `nitroreel.net` куплен и подключён (Cloudflare как DNS-хост,
  A-запись на Vercel, без проксирования). **Email и соцсети всё ещё выдуманы** —
  `hello@nitroreel.net` никуда не доставляется, почта не настроена, впишем реальные позже.
  **Проверено 2026-08-11:** ссылка на Behance в футере (`site.ts` → `behance`) ведёт на
  404 — аккаунта не существует. Instagram и YouTube отдают 200, но реальное наполнение

  снять ссылку из футера).

## Известные пробелы

- **Supabase и Telegram подключены и проверены** (`.env.local` локально, те же ключи —
  в Vercel Production). Засыпание бесплатного Supabase закрыто ежедневным Cron-keepalive
  (см. раздел «База» выше) — не считай это открытым пробелом.
- **Rate limit протекает на serverless** — счётчик в памяти процесса, на Vercel
  инстансов несколько. Осознанный компромисс, а не недосмотр. Если понадобится жёстче:
  Upstash Redis или counting-запрос в Postgres. От спама раньше поможет Cloudflare
  Turnstile, а не идеальный лимитер.
- **Видео стоит вынести на видеохостинг** (`bunny` / `cloudflare` / `mux` уже
  поддержаны). Исключение — хиро-луп: он остаётся `provider: "file"`, иначе сторонний
  плеер утянет LCP. Подробности в `HANDOFF.md`, Шаг 5.
